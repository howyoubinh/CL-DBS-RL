# STM32F746NGH6 (Cortex-M7) measurements, 2026-10-22

Build: Arm GCC 7.2.1, -O3, hard-float, -ffp-contract=off, no fast-math, I/D caches on, code+weights in internal flash, working memory in DTCM.
Timing: DWT CYCCNT / clock, mean over 100 windows x 3 repeats. Reference checks: CMSIS-NN int8 == TFLite interpreter int8 on 100/100 windows; int16 == float32 decisions on 98/100 (expected: package README).

| implementation | 216 MHz latency | cycles (derived) | 48 MHz latency |
|---|---|---|---|
| MLP float32, plain C | 1.037 ms | 223,953 | 4.211 ms |
| MLP int8, TFLite model via direct CMSIS-NN calls | 0.311 ms | ~67,200 | 1.273 ms |
| MLP int8, reference C | 0.518 ms | ~111,900 | |
| MLP int16, reference C | 1.153 ms | ~249,000 | |
| SNN float32, straightforward C (not architecture-optimised) | ~118 ms per 100-step window | ~25.5 M | |

Wake from Stop every ~100 ms: inference latency unchanged; HSE/PLL + clock restoration 0.275 ms after wake.

Power: estimated from the datasheet typical active current (109 mA at 3.3 V = 0.36 W active).
Energy per inference (estimate): float32 0.37 mJ, int8 (CMSIS-NN) 0.11 mJ.
Energy per ~100 ms cycle incl. Stop, wake-up and clock restoration (estimate): float32 0.62 mJ, int8 0.36 mJ.

Derived: energy per cycle at 216 MHz = 0.36 W / 216 MHz = 1.67 nJ/cycle. Low-power Cortex-M4F/M33 estimate at ~33 pJ/cycle (Apollo4 class): float32 224k cycles -> 7.4 uJ/inference; int8 CMSIS-NN 67k cycles -> 2.2 uJ/inference (+ sleep).
